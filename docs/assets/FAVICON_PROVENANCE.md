# Favicon provenance

`app/favicon.ico` is an original asset created for this repository in Issue #53. It repeats the existing two-column mark in `components/site-header.module.css` and Design System v2: blue #2563EB on white, tall left column and shorter right column. No third-party icon, font, image or trademark asset was downloaded. `favicon-source.svg` records the geometry; ICO contains16/32/48pixel variants. The contribution follows the repository's licensing terms; no third-party license is required. This is a browser-size derivative of the existing identity, not a brand redesign.
